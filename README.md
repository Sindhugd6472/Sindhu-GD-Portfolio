# Sindhu Govindareddy Doddamane Portfolio

Personal portfolio website for Design Verification, RTL Design, FPGA, ASIC Verification, and SoC Validation roles.

## Live Site Options

You can deploy this website using either GitHub Pages or Netlify.

## Deploy with GitHub Pages

1. Open this repository on GitHub.
2. Go to **Settings**.
3. Go to **Pages**.
4. Under **Build and deployment**, choose:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/root**
5. Save.

Your site will usually be available at:

```text
https://sindhugd6472.github.io/Sindhu-GD-Portfolio/
```

## Deploy with Netlify

1. Go to Netlify.
2. Choose **Add new site > Import an existing project**.
3. Connect GitHub.
4. Select `Sindhugd6472/Sindhu-GD-Portfolio`.
5. Leave build command empty.
6. Set publish directory to:

```text
.
```

7. Deploy.

## Resume Setup

The resume button currently points to:

```text
assets/Sindhu_GD_Resume.pdf
```

Create an `assets` folder and upload your resume with that exact filename, or update the resume link inside `index.html`.
