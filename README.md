## Portfolio site

The website is implemented in `index.html`, with supporting `styles.css` and `script.js`.

### Deploy on GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**.
4. Save.

Once GitHub Pages is enabled, the expected URL is:

https://sindhugd6472.github.io/Sindhu-GD-Portfolio/

### Resume

The current website provides a contact link rather than a downloadable resume. Before adding a resume-download button, upload a **public-safe, current** PDF to the repository, e.g. `assets/Sindhu_GD_Resume.pdf`, then link to that file from `index.html`. Do not publish confidential employer material or personal identifiers you do not want to make public.

### Portfolio maintenance checklist

- Keep the Arm experience section factual and free of confidential implementation details.
- Link each featured project to its current public repository.
- Include only projects and skills you can explain in an interview.
- Recheck project run instructions and CI status after updates.
- Update the résumé and relocation availability separately when plans are finalized.
